# Web Media Showcase

Three small front-end projects that show responsive design, JavaScript interaction, and SVG animation.

**Live demo:** https://codedbymelissa.github.io/Web-Media/

## What it shows

| Demo | Skills |
| --- | --- |
| Responsive photo grid | Bootstrap grid, CSS media queries, `resize` event |
| Wake the corgi | DOM events, Web Animations API, async/await |
| Animated apple tree | Inline SVG, CSS3 animation with animate.css, class toggling |

## Built with

HTML5, CSS3, JavaScript (no jQuery), Bootstrap 5, animate.css, Google Fonts.
