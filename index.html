Web Media Showcase

Three small projects that show how I build responsive layouts, interactive pages, and animated graphics with HTML, CSS, and JavaScript.

Responsive design

A photo grid that changes from one column on phones to four on large screens, and a message that reports which layout you are seeing. Resize your browser window to try it.

Checking your screen size...

Built with: Bootstrap grid, CSS media queries, JavaScript resize event

JavaScript interaction

Click the photo or the button to wake the corgi. The fade and pop-up are made with the Web Animations API, and the button toggles the scene back.

Zzz...

Built with: JavaScript DOM events, Web Animations API, async/await

SVG and animation

An apple tree drawn in SVG. Each button applies a different CSS3 animation to one apple using animate.css.

Choose an apple

Built with: inline SVG, CSS3 animation (animate.css), JavaScript class toggling
