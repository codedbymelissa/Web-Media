Powerlifting Web Media Showcase

Three small projects that show how I build responsive layouts, interactive pages, and animated graphics with HTML, CSS, and JavaScript, all built around the squat, bench press, and deadlift.

By Melissa Grix. Back to my resume site

Responsive design

A grid of the three competition lifts plus the gear that goes with them. It changes from one column on phones to four on large screens, and a message reports which layout you are seeing. Resize your browser window to try it.

Checking your screen size...

Built with: Bootstrap grid, CSS media queries, JavaScript resize event

JavaScript interaction

Click the photo or the button to lift the bar. The fade and the press to lockout are made with the Web Animations API, and the button re-racks the bar.

Bar is loaded. Chalk up...

Built with: JavaScript DOM events, Web Animations API, async/await

SVG and animation

A loaded barbell drawn in SVG. Each button applies a different CSS3 animation to one plate using animate.css.

Choose a plate

Built with: inline SVG, CSS3 animation (animate.css), JavaScript class toggling
